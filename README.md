# 同事小學堂｜簡報試玩版（待審閱）

直接使用現代瀏覽器開啟 `index.html`，不需網路、安裝或後端。聊天軟體的附件預覽可能不執行 JavaScript，請下載後以瀏覽器開啟。

- 使用 demo01–demo05（不分大小寫），畫面可點選帶入；共用示範密碼 `Learn123!`（區分大小寫），純示範身分切換，並非安全公司驗證。
- 同一瀏覽器記住示範身分；登出可切換。儲存受限時仍可試玩，會顯示提示。file:// 的保存行為依瀏覽器而異。
- 人物猜猜看：隨機同事（排除自己、不連續重複），每回合 5 題，含職務／合作偏好與解析。
- 任務找幫手：5 題工作情境，答題後解析與回合分數。
- 認識同事：姓名、職務、職責搜尋，多筆結果、展開筆記、查無結果；與出題獨立。
- 分數不保存、不排名、不用於員工評核。切換功能結束當前回合。

## 資料與界線
人物資料來源為委派簡報提供內容，無外部查證。張靖欣、黃小琪、蘇詠哲依提供資料；陳柏宇、林語安明確標示為虛構。插畫不是本人肖像；MBTI 僅展示，未推論特質。黃小琪職責保留「自費診所系教學培訓顧問」，「系」是否為「系統」待確認；未推定性別。蘇詠哲溝通偏好為提供原意的編輯整理。

純前端原型，所有人物資料均可由讀取檔案取得。未實作正式登入、權限、後端或部署；不得當作機密員工系統。正式上線、人物資料及肖像使用需人類確認與授權。
